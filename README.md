# Mi Biblioteca Digital

Aplicación de biblioteca digital privada.

Este repositorio contiene los archivos públicos necesarios para servir la interfaz web. Los documentos personales de la biblioteca no se almacenan en este repositorio.

La aplicación utiliza autenticación y controles de autorización para proteger el acceso al contenido. No publiques credenciales privadas, claves de servidor ni archivos personales en este repositorio.
